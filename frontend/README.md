# PosQ Kasir — Frontend SPA

Frontend aplikasi kasir PosQ dibangun dengan **Vite + React 18** dan **Tailwind CSS**.

## Perintah Pengembangan

- `npm run dev` : Menjalankan Vite dev server di port 9990 dengan HMR dan proxy API ke backend.
- `npm run build` : Mengompilasi aplikasi ke folder `dist/` untuk produksi.
- `npm run preview` : Meninjau hasil build produksi secara lokal.
